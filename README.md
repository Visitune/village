# Excel → Dashboard (SPA HTML) avec Copilot

**Un seul fichier à suivre : `INSTRUCTIONS-COPILOT.md`.** Le modèle à copier est `modele/spa-modele.html`.

Résultat attendu : Copilot livre un fichier `dashboard.html` COMPLET (HTML + CSS + JS). Il n'écrit PAS de bloc « CONFIG ».

## Utilisation
1. Joindre l'Excel dans Copilot.
2. Coller le texte du fichier `DEMARRER.md`.

## Contenu
- `DEMARRER.md` : le texte à coller dans Copilot.
- `INSTRUCTIONS-COPILOT.md` : la procédure détaillée pour Copilot.
- `modele/spa-modele.html` : le modèle de SPA générique (seul le bloc `MAPPING` change).
- `ancienne-voie-moteur/` : ancienne méthode (moteur d'audit SafetyCulture + bloc CONFIG). **Ne pas utiliser pour la demande « fais-moi un dashboard à partir de cet Excel ».**
